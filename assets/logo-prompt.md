# Logo direction: a repaired loop

A compact loop with one visible repair seam connects the name Scar to its purpose: a past mistake leaves a useful trace. Use a simple silhouette that reads at avatar size, with a restrained terracotta accent. The README currently uses a text heading while this direction is explored; the original logo is preserved in `logo.png`.

## Image-generator prompt

Design a minimal logo for “Scar”, an open-source developer tool that turns feedback from past coding mistakes into checks for future work.

Create one compact, almost circular loop with a single diagonal break. Bridge that break with a small, precise terracotta stitch: the repaired section is the distinctive feature. The meaning is a useful trace of a past mistake, learning through repair. Make the form geometric and balanced, with an unmistakable silhouette that still works at 24 pixels. Flat vector-style artwork, consistent stroke weight, generous negative space. Main color deep charcoal (#202B36), repair accent muted terracotta (#D97757). Transparent background with completely clean edges.

Deliver one centered symbol only, large on a square canvas. No text, letters, mockups, gradients, shadows, grain, glow, texture, literal wounds, medical imagery, robots, brains, circuit boards, or generic AI sparkles. It should feel like a precise, understated tool for developers.

## Finishing

Redraw the chosen mark as SVG before using it in the README. Add “Scar” as real typeset text rather than generated lettering. Prepare a light version with charcoal strokes and a dark version with off-white strokes, keeping the terracotta seam in both. Check the symbol at 24 px and the wordmark at 160 px wide.

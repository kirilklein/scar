## Memory System

After completing a non-trivial feature or debugging session, review what was learned and update the relevant memory file below. Focus on: gotchas, non-obvious patterns, decision context, and test quirks. Keep entries concise and actionable.

**Topic files** (see this directory):
- `cross-repo-patterns.md` — patterns spanning multiple repos
- `debugging.md` — hard-won debugging insights
- `workflow-gaps.md` — tracks when pipeline steps miss things (auto-populated by /ship, /triage-ci)
- `workflows/` — reusable workflow recipes (see `workflows/README.md`)

**Repo-specific lessons** live in each repo's `.claude/lessons.md` (checked into git). Update those directly when working in a specific repo.
